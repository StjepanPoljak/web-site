## Overview

Android smartphone client communicating with Python server on a Raspberry Pi
(via HTTP REST API) dedicated to playing FLAC audio. Also included is
installation script and services for Raspberry Pi.

## Technical focus

- Android client written in Kotlin
- Python HTTP server

## What I worked on

- file system retrieval via REST API
- simple FLAC playing logic
- playlist creation
- services enabling automatic discovery and persistence of the Python server
