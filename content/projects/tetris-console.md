## Overview

A hardware Tetris implementation built on two PIC microcontrollers programmed in
assembly. The system used an old Philips remote controller as input along with
custom display and control logic.

## Technical focus

- embedded systems design
- assembly programming
- microcontroller communication
- input decoding (IR remote signals)

## What I worked on

- implemented game loop in assembly
- designed input handling via IR receiver
- coordinated logic across two microcontrollers

Completed.
