## Overview

A simple instruction and memory emulator of 6502 chips written in C, along with
a lightweight 6502 assembly to machine code translator. Also a helper static
C code generator written in Python (parsing 6502 specification directly into
code).

## Technical focus

- 6502 CPU and memory internals
- C, 6502 assembly
- Python

## What I worked on

- machine code execution loop
- assembly parsing and translation to machine code
- static C code generation in Python
- guest memory implementation
- infrastructure for device pipeline

## Status

Experimental.
