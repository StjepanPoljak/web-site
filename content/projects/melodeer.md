## Overview

A low-level audio library written in C using OpenAL API able to decode and play
FLAC files (with basic support for MP3 and WAV). Included is the Melodeer TUI
also written in C, allowing file and folder listing, playlist creation and
spectral visualization utilizing Fast Fourier Transform (tested on MAC and Linux
terminals).

## Technical focus

- multi-threaded environment in C
- OpenAL API
- FLAC, MP3 and WAV API
- Fast Fourier Transform

## What I worked on

- low-level audio pipeline using OpenAL
- decoding and playing FLAC, MP3 and WAV
- buffering and garbage collection logic
- Linux / MAC terminal user interface
